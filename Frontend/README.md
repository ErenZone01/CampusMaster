# 🚀 Démarrage Rapide - CampusMaster

## Installation et Lancement

```bash
# Installer les dépendances
npm install

# Démarrer le serveur de développement
npm run dev
```

L'application sera disponible sur [http://localhost:3000](http://localhost:3000)
